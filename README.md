# Movie Search (React Query)

Пошук фільмів через TMDB API з пагінацією. React + TypeScript + Vite, TanStack Query, React Paginate, axios, react-hot-toast, CSS Modules, modern-normalize.

Для запуску створи файл `.env` з токеном TMDB:

```
VITE_TMDB_TOKEN=your_token
```

```bash
npm install
npm run dev
```
